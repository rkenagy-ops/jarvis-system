# GitHub open source

Use the `oss` tool.

- `search` — find repos (`query`)
- `readme` — read a repo README (`repo` = owner/name)
- `ingest` — copy README + metadata into `Sources/github/`
- `starter_pack` — ingest the curated OSS list (n8n, Stirling, whisper, yfinance, trafilatura, …)
- `awesome` — mine public-apis / awesome-selfhosted / awesome-python tables
- `public_apis` — search the public-api-lists JSON index
- `huggingface` — models / datasets
- `youtube` — transcript

Do not clone entire monorepos into the workspace. Ingest READMEs, then fetch only the files you need.
