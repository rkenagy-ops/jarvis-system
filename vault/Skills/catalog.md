# Open API catalog

When the owner asks for facts that live in a public dataset, call `catalog` instead of guessing.

- Papers: `arxiv`, `semantic_scholar`, `pubmed`
- Web: `jina` (URL), `duckduckgo`, `archive`
- Markets: `fx`, `sec_edgar`, `defillama`, `fear_greed`, `coingecko`
- Places: `geocode`, `countries`, `holidays`, `nws`, `earthquakes`
- Code: `pypi`, `npm`, `crates`, `github`
- Security: `cve`, `cisa_kev`, `crtsh`, `rdap`
- Other: `dictionary`, `wikidata`, `nasa`, `worldbank`, `gutenberg`, `open_library`
