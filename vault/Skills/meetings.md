# Meeting minutes (Meetily's job, our vault)

Do **not** install Meetily / Whisper / a second app.

1. Paste the transcript or rough notes in chat (or say **File minutes**).
2. Jarvis calls `meeting file` → `vault/Meetings/YYYY-MM-DD-HHMM-slug.md`
3. Decisions + `- [ ]` action items land in that note and today's Daily.
4. Open tasks show in the HUD because `Meetings/` is on the task scan.

Mark a line `Action: …` or `Decision: …` if you want guaranteed extraction.
If you later install Meetily standalone, drop its transcript here the same way.
